# PHY2039 2026–27

This repository contains the working materials for **Scientific Computation
with Python (PHY2039)** for the 2026–27 academic year.

## Rollover workflow

The complete tracked 2025–26 course is retained in [`archive/2526/`](archive/2526/).
That folder is a reference snapshot: leave material there until it has been
reviewed for the new academic year.

As each topic is prepared, move or copy the relevant files into the active
top-level folders and add them to `config.yml`:

- `content/` – current teaching pages and slides
- `static/` – current images, downloads, styles and scripts
- `notebooks/` – current source notebooks, when needed

Keeping reviewed material outside `archive/2526/` makes the rollover status
visible from the repository layout.
